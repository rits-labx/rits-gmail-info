プライバシーポリシー

制定・最終更新：2026年10月17日

1. 運用者と適用範囲

運用者はrits（リツ）個人プロジェクトです。本方針は、Rits GmailによるGoogleユーザーデータの取り扱いと、この説明サイトに適用します。連絡先：rits.labx@gmail.com

2. アクセスするデータと権限

本人によるGoogleの認証と許可に基づき、Gmail APIの読み取り専用権限（gmail.readonly）を使用します。接続先メールアドレス、メッセージID、送受信者・件名・日時などのヘッダー、本文・要約、必要な添付ファイルを取得します。アカウントごとに接続先を照合します。Googleアカウントのパスワードを本連携が収集・保存することはありません。

3. 利用目的

  • 本人の指定に応じたメールの検索、本文の確認、添付の取得。
  • 重要メールや取引上の対応候補の検出、重複処理の防止、本人への通知。
  • 本人が依頼した会話エクスポート等の検出・取得と、既存の保管処理への引き渡し。
  • 接続状態の確認、障害の診断、処理の復旧。

4. 保存場所と保存期間

認証トークンは本人のWindows環境でDPAPIにより暗号化して保存します。必要なメール情報、添付、取得済みID、判定結果、通知履歴、診断ログは、本人のPC等の処理用保存先に保存されることがあります。すべてのメールを常時複製することは目的としていません。本人が依頼する資料の保管では、本人のGoogle Drive等へ保存する場合があります。

利用や再処理防止に必要な期間保持し、不要となったデータは本人の判断・依頼により削除します。一律の自動削除期限は現在設けていません。Google側で許可を取り消しても、すでに保存したデータが自動で削除されるわけではありません。

5. 外部サービスへの提供

一部のメール候補は、必要な内容をOpenAIのサービスへ渡して分類・要約する場合があります。本人向けLINE通知では、件名や必要な要約、対応事項等がLINEのサービスへ送られる場合があります。本人の依頼に応じてGoogle Drive等へ資料を保管する場合があります。各サービス側の処理・保持には、そのサービスに適用される利用条件とプライバシーポリシーが適用されます。

本連携のGoogleユーザーデータの利用・他アプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。データの販売、広告目的の利用、汎用AIモデルの開発・学習を目的とした利用は行いません。

6. 安全管理とアクセス

本人の利用するアカウントを明示し、読み取り専用権限で運用します。認証トークンやクライアント秘密情報をこの公開サイトへ掲載しません。メール本文等を人が確認するのは、本人が依頼した操作やサポート・障害対応など、必要かつ許可された範囲に限ります。

7. 許可の取り消しと削除依頼

本人はGoogleアカウントのサードパーティ接続管理から本連携のアクセス許可を取り消せます。保存済みデータの削除・利用停止や本方針に関する問い合わせは、上記連絡先で受け付けます。

8. この公開サイトについて

このサイトにはメール取得処理、問い合わせフォーム、独自のアクセス解析、広告を設けません。ホスティング事業者がアクセスログ等を処理する場合があります。GitHub Pagesで公開する場合はGitHubのプライバシーに関する説明も参照してください。

9. 方針の変更

連携の動作や利用するサービスが変わる場合は、本ページを更新して最終更新日を示します。新しいアクセス権限が必要な場合は、Googleの認証画面等で本人の許可を得ます。
